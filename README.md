# STM32
# 基于 STM32 的简易电子琴

## 1. 项目简介

本项目基于 STM32F103 开发板实现一个简易电子琴。程序通过按键扫描获取用户按下的按键，并根据按键编号设置蜂鸣器输出频率，从而发出不同音调；松开按键后蜂鸣器停止发声。

当前程序内置 7 个测试频率（1000 Hz～7000 Hz），按键 1～7 分别对应 7 个频率，适合用于学习 STM32 的 GPIO 输入、按键扫描、蜂鸣器控制和定时器/PWM 输出。

## 2. 硬件资源

- STM32F103 开发板（如正点原子战舰 STM32F103 V3）
- 蜂鸣器模块（连接引脚由 `buzzer.h` / `buzzer.c` 决定）
- 7 个按键（连接引脚由 `key.h` / `key.c` 决定）
- 下载器：ST-Link / J-Link / USB 串口（按实际开发板选择）

> 注意：蜂鸣器控制引脚和按键引脚需与实际硬件连接一致，否则按键或发声功能不生效。

## 3. 功能说明

1. 系统上电后完成系统时钟、延时、按键和蜂鸣器初始化。
2. 主循环不断调用 `Key_Scan()` 扫描按键。
3. 当按键编号为 1～7 时，调用 `Buzzer_SetFreq()` 设置对应频率：
   - 按键 1 → 1000 Hz
   - 按键 2 → 2000 Hz
   - 按键 3 → 3000 Hz
   - 按键 4 → 4000 Hz
   - 按键 5 → 5000 Hz
   - 按键 6 → 6000 Hz
   - 按键 7 → 7000 Hz
4. 无按键按下时，调用 `Buzzer_Stop()` 停止蜂鸣器发声。

## 4. 软件结构

| 文件 | 作用 |
|---|---|
| `main.c` | 主程序：初始化系统与外设，循环扫描按键并控制蜂鸣器频率 |
| `buzzer.c` / `buzzer.h` | 蜂鸣器驱动：初始化、设置频率、停止发声 |
| `key.c` / `key.h` | 按键驱动：按键初始化与按键扫描 |
| `delay.c` / `delay.h` | 延时函数初始化与延时功能 |
| `stm32f10x.h` | STM32F10x 标准外设库头文件 |

主程序流程：

```c
SystemInit();      // 系统时钟初始化
delay_init();      // 延时函数初始化
Key_Init();        // 按键初始化
Buzzer_Init();     // 蜂鸣器初始化
Buzzer_Stop();     // 初始状态停止发声

while (1)
{
    key = Key_Scan();          // 扫描按键
    if (key >= 1 && key <= 7)
        Buzzer_SetFreq(tones[key - 1]);  // 设置对应频率
    else
        Buzzer_Stop();                   // 无按键则停止
}
```

## 5. 编译与运行

1. 使用 Keil MDK 打开工程（或按实际开发环境新建工程）。
2. 将 `main.c`、`buzzer.c`、`key.c`、`delay.c` 及对应头文件加入工程。
3. 确认蜂鸣器和按键引脚与开发板实际连接一致。
4. 编译工程，下载到 STM32F103 开发板。
5. 复位运行后，按下按键 1～7，蜂鸣器发出对应频率声音；松开按键后停止。

## 6. 实验现象

- 按下按键 1～7 时，蜂鸣器发出不同音调。
- 松开按键后，蜂鸣器停止发声。
- 不同按键对应频率从 1000 Hz 到 7000 Hz 依次升高。

## 7. 注意事项

1. 当前 `tones[]` 中为 7 个测试频率，不是标准音阶频率；如需演奏乐曲，可替换为实际音符频率表。
2. 若蜂鸣器为无源蜂鸣器，可通过 PWM 输出不同频率实现音调变化；若为有源蜂鸣器，通常只能控制响/停，不能直接改变音调。
3. 按键扫描如出现抖动，可在 `Key_Scan()` 中加入软件消抖或延时消抖。
4. 蜂鸣器控制引脚、按键引脚和有效电平需根据实际硬件修改 `buzzer.c` / `key.c`。
5. 主循环中未加入额外延时，按键扫描频率较高；如需降低 CPU 占用，可加入短延时。

## 8. 可扩展方向

- 增加更多按键，扩展音阶范围。
- 使用定时器 PWM 精确输出标准音符频率。
- 增加按键消抖和长按/连按逻辑。
- 支持乐曲自动播放功能。
- 增加数码管或 OLED 显示当前音符。
